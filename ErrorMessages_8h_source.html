5// ------------------------------------------------------------
6// R97 #1 fix: 三后端（Interpreter / StackVM / RegisterVM）原本各自
7// 维护错误消息字符串字面量，导致同一语义的错误消息文本不一致
8// （如 "数组索引必须是整数" vs "数组索引需要整数类型"）。
9// 本头文件集中定义三后端共享的运行时错误消息常量，三后端引用同一
10// 常量保证文本一致性。TestThreeEnginesConsistency 中相关 EXPECT_NE
11// 测试可改为 EXPECT_EQ 验证一致性。
12//
13// 使用原则：
14// - 仅统一"三后端可能产生但消息文本不一致"的错误消息
15// - 栈下溢等内部错误（各后端独有）不在此统一
16// - 含动态参数的消息（如 "数组索引越界: %lld"）仍用 ErrorFormat::format
17//
18// P3-16 fix: 新增 *FmtStd 常量（std::format 风格占位符 {}），
19// 与 *Fmt（printf 风格 %d/%s）一一对应。新代码应优先使用 *FmtStd +
20// ErrorFormat::formatStd。老 *Fmt 常量保留兼容现有调用方。
21// 迁移示例：
22// // legacy
23// ErrorFormat::format(kRecursionDepthExceededFmt, limit)
24// // modern（推荐）
25// ErrorFormat::formatStd(kRecursionDepthExceededFmtStd, limit)
26// ============================================================
