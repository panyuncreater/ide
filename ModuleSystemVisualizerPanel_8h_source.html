3// ============================================================
4// ModuleSystemVisualizerPanel — 模块系统可视化教学面板
5// ------------------------------------------------------------
6// 可视化 MiniLang 模块系统的核心机制：import/export 语义、路径解析、
7// 模块缓存、循环依赖检测、预扫描阶段（FunDecl/ExportStmt）、错误传播链。
8//
9// 模块系统是 MiniLang 的高频 Bug 模式（路径安全、循环依赖、预扫描遗漏
10// FunDecl/ExportStmt、错误传播），本面板以预设数据 + 交互式模拟器方式
11// 教学这些概念，不运行执行引擎。
12//
13// 两个子页：
14// 1. 模块系统原理：HTML 文档 + 概念表 + 路径解析规则表 + 预扫描清单
15// 2. 交互式模块依赖模拟器：4 个预设场景（正常导入链 / 循环依赖 /
16// 路径解析失败 / 预扫描遗漏）+ 加载顺序时间轴 + HTML 依赖图与日志
17//
18// 设计约束：
19// - 面板构造函数不创建标题栏（Ide::wrapTeachingPanel 自动包裹）
20// - setController 内联实现（仅赋值，面板不依赖控制器运行）
21// - 纯教学/模拟面板，不运行任何执行引擎
22// - 字体使用 GuiTextUtils::monospaceFont(N) 工厂
23// - 静态教学数据用 static const 局部变量模式（参考 GcVisualizerPanel）
24// ============================================================
