## 2026-07-09 · 第六十八轮：UI 三大顽疾真正根因修复——ADS loadStylesheet 覆盖（P1 × 3，共 3 项）

### 概述

本轮针对用户反馈"全都没解决"的三个 UI 问题（经第六十五~六十七轮修复均无效）进行**真正根因定位**。前几轮的根因分析全部错误——真正原因不是 QFluentKit StyleSheetManager，而是 **ADS 自身的 `loadStylesheet()` 机制**：`applyFluentStyle()` 中 `setPalette(pal)` 向 dockManager_ 传播 `QEvent::ApplicationPaletteChange` 事件，ADS eventFilter 检测到 `ColorSchemeMode == FollowPalette`（默认值）→ 调用 `loadStylesheet()` → `setStyleSheet(default.css)` → **完全覆盖**自定义 adsQss。

**统一修复**：添加 `ads::CDockManager::DisableStylesheet` 配置标志，使 `loadStylesheet()` 成为 no-op，自定义 adsQss 才能持久存在。全量 1758/1758 测试通过。

### 问题与修复对应表

| # | 严重性 | 类型 | 位置 | 修复内容 |
|---|--------|------|------|----------|
| 1 | P1 | 样式覆盖（真正根因） | `app/ide.cpp` setConfigFlags | **ADS dock 标签蓝底+米黄字体**——`setPalette` 传播 `ApplicationPaletteChange` → ADS `loadStylesheet()` 覆盖自定义 QSS。修复：`DisableStylesheet` 标志使 `loadStylesheet()` 成为 no-op。 |
| 2 | P1 | 样式覆盖（同一根因） | `app/ide.cpp` setConfigFlags | **编译分析面板字节码背景未变米黄色**——同一根因。DisableStylesheet 修复后 adsQss 的 dock 容器背景规则生效。 |
| 3 | P1 | 布局干扰（同一根因） | `app/ide.cpp` setConfigFlags + QTimer 顺序 | **面板初始大小每次都要手动调整**——restoreState 后的 applyFluentStyle→setPalette→loadStylesheet→setStyleSheet 触发样式重算干扰 splitter 尺寸。DisableStylesheet 消除此干扰 + applyFluentStyle 移到 restoreState 之前。 |

### 关键教训

1. **`setPalette` 会向子 widget 传播 `ApplicationPaletteChange` 事件**——ADS eventFilter 利用此事件在 `ColorSchemeMode==FollowPalette` 时重新加载样式表。
2. **ADS `ColorSchemeMode` 默认值为 `FollowPalette`**——任何 palette 变化都会触发 loadStylesheet。
3. **前几轮根因分析全部错误**：归咎于 "restoreState 时机"/"QFluentKit registerWidget"/"ADS default.css QLabel 规则"，均未发现 `setPalette → ApplicationPaletteChange → loadStylesheet` 因果链。

## 2026-07-09 · 第六十七轮：UI 三大顽疾根因修复（P1 × 2 + P2 × 1，共 3 项）

### 概述

本轮针对用户反复反馈（经三轮修复均未解决）的三个 UI 问题进行彻底根因排查并修复。定位字节码背景问题的根因为 QFluentKit `StyleSheetManager::updateStyleSheet` 在主题信号触发时重新应用 `list_view.qss`（`background: transparent`）覆盖自定义 `itemViewQss`。全量 1758/1758 测试通过。（注：本轮根因分析实际错误，真正根因见第六十八轮。）

### 问题与修复对应表

| # | 严重性 | 类型 | 位置 | 修复内容 |
|---|--------|------|------|----------|
| 1 | P1 | 样式覆盖 | `app/ide.cpp` applyFluentStyle registerWidget | 移除 5 个控件的 registerWidget 调用，由 itemViewQss 统一样式化。 |
| 2 | P1 | 样式覆盖 | `app/ide.cpp` applyFluentStyle adsQss | 添加 ADS tab QLabel 子选择器规则，防止 default.css 的 palette 规则干扰。 |
| 3 | P2 | 布局恢复 | `app/ide.cpp` restoreLayout | restoreState 延迟到 QTimer::singleShot(0) 中执行，确保窗口几何有效。 |

### 关键教训

1. **QFluentKit registerWidget 是双向承诺**——注册后 QFluentKit 获得 stylesheet 管理权，会在主题信号时重新应用其 QSS。
2. **ADS default.css 的子选择器规则容易被忽略**——影响子控件（QLabel）颜色。
3. **Qt 窗口几何在 showEvent 中可能无效**——依赖容器几何的 API 应延迟到事件循环空闲后调用。
