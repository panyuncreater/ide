# 2026-10-24 全模块缺陷轮

> 范围：Lexer/Parser/AST、解释器运行时、StackVM/RegisterVM、JIT、编译器/IR、Common/Formatter/Lint/CAPI、GUI、CLI/App ｜ 方法：8 模块并行只读审计 → 分组修复 → 五目标构建 + 全量 ctest ｜ 基线：`b580cbe` + 工作树 ｜ 验证：4236/4236

## 已修复

### 解析器

- **P0 enum 错误恢复死循环**：`enumDecl()` catch 中 `synchronize()` 在 `var/fun/class` 等同步关键字处不消费 token，循环无进展检查。修复为同步后位置未前进则强制 `advance()`。回归：`AuditRound2.ParserEnumBadVariantTerminates`。
- **Parser 复用状态泄漏**：`parse()` 未清 `knownMacros_`/`knownTraits_`，旧 AST 的裸声明指针跨轮存活。修复为每次 parse 清空两表。回归：`AuditRound2.ParserReuseClearsMacroAndTraitTables`。

### 运行时与 VM

- **增量 GC 漏类闭包环境**：`classRegistry_` 根只遍历字段默认值，漏 `ClassInfo::closureEnv`；函数内定义的类所捕获容器会被误清空。修复为对 closureEnv 走环境链根收集。回归：`AuditRound2.InterpreterGcKeepsClassClosureEnv`。
- **StackVM 名称版全局缓存悬垂**：类定义/接收者写回插入 `globals_` 后未递增 `globalsVersion_`，rehash 使 `varCache_.valuePtr` 悬垂。修复为两处插入均递增版本。RegisterVM 类重定义补 `methodCache.clear()`。
- **RegisterVM 类标记缺失**：`REG_DEFINE_CLASS` 只填 `classInfo_`，未写 `"class:"+name` 全局标记，`print(A)` 与另两后端不一致。修复为按槽位/名称表写入并失效缓存。回归：`AuditRound2.RegisterVmClassMarker`。

### JIT

- **操作数栈无边界检查**：建帧只查 `MAX_FRAMES`，局部槽总量可越过 8 KB 操作数栈覆盖 helper 帧。修复：栈扩至 2048 槽 + 256 槽余量，`stackLimit` 写入 prologue，fast path 与四个 C++ 建帧 helper 全部检查，超限按递归深度错误退出。回归：`AuditRound2.JitOperandStackBoundsGraceful`。
- **Safepoint GC 根不完整**：只扫 `globalSlots` + 固定 1024 槽，漏 `globals_`、类字段默认值、闭包/关闭 upvalue、`lastMutatedReceiver_` 与深栈帧。修复为扫描 `[stackTop, stackBase)` 并收集全部 JIT 侧持有。回归：`AuditRound2.JitSafepointKeepsBlockGlobalCycle`。
- **类型注解在 JIT 被跳过**：`OP_TYPE_CHECK` 直接 `ip += 3`。修复为实现 peek 检查（`typeMatchValue` + 实例继承链），失败报类型注解违反。回归：`AuditRound2.JitTypeCheckEnforced`。
- **NaN 比较与非数值算术分歧**：EQ/NEQ 把 `0x7FFC` NaN 当 INT 走 raw bits；通用算术对 string 等调 `toDouble()` 静默得 0。修复为 NaN 走 generic、算术 helper 补 `isNumber` 检查并经统一错误路径抛出。回归：`AuditRound2.JitNaNEqualityUsesGenericPath`、`JitNonNumericArithmeticErrors`。
- **循环计数跨站点/跨调用累计**：`loopIterations_` 按 chunk 单槽，同一函数两个有限循环或反复调用会误报无限循环。修复为每 chunk 16 个循环站点槽，进入 chunk 时重置；超过 16 个循环的函数 JIT 显式编译失败，不执行陈旧计数代码。回归：`AuditRound2.JitLoopLimitPerSiteAndPerCall`。
- **缓存可观测性**：`asmCaptureEnabled_` 纳入块缓存键，`chunkTiers_` 随缓存条目保存/恢复；codegen 版本升至 4。

### IR / 工具链 / GUI

- **IR 解构遮蔽丢失**：顶层块遮蔽预扫描只收 `NODE_VAR_DECL`，解构绑定直接写 GLOBAL_SLOT。修复为解构名同规格保存/恢复。回归：`AuditRound2.IRDestructureShadowRestoresOuter`。
- **pkg 路径穿越**：包名/版本直接拼路径，`../` 可把 registry 内容复制到包目录外并在哈希失败时递归删除。修复为包名/版本白名单 + canonical 前缀校验，`resolveModule` 同样限制在 packagesDir 内。回归：`AuditRound2.PkgRejectsTraversalNames`。
- **Lint 一等函数误报**：`visitVarRef` 不标记函数引用，`map(arr, d)` 触发 UnusedFunction；standalone `--fix` 可误删。修复为 VarRef 命中函数表时标记 used；统一入口 `minilang lint --fix/--fix-dry-run` 路由到修复管线。
- **Formatter 丢失 `const`**：`const fun` 格式化后退化为普通函数，编译期折叠路径消失。修复为输出 `const ` 前缀。回归：`AuditRound2.FormatterKeepsConstFun`。
- **LSP/DAP 协议边界**：`std::stoul(Content-Length)` 可抛异常终止服务器且无上限；`startFrame` 负数越界读。修复为共享 `parseContentLength`（32 MiB 上限）与 `clamp`。回归：`AuditRound2.ProtocolContentLengthBounds`。
- **GUI 生命周期**：`closeEvent` 在 `maybeSave()` 前 disconnect，取消关闭后 controller 信号/面板监听器不恢复；`SyntaxExplorerPanel` 临时 Interpreter 未隔离；`VmStackSandboxPanel` 运行期缺守卫。修复为可取消确认前置、监听器挂起/恢复、`GcTriggerPolicy::Isolated`、运行期守卫。
