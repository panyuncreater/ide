## 新报告模板

```markdown
# <日期> 审计轮

> 范围：... ｜ 方法：... ｜ 基线：<commit> ｜ 验证：ctest N/N
> 开放项：见 docs/BACKLOG.md（本报告不复制清单）

## 已修复
- <ID/主题>：根因、修复、回归测试名、语义影响

## 未修复
- B-xxx：一句结论 + 证据位置（详情只写 BACKLOG）
```

## 归档规则

1. 报告按日期独立成文件；跨日轮次另起文件，不在旧报告末尾续写。
2. 已修复条目只保留“根因 + 修复 + 回归锁”三要素，不写操作过程。
3. 报告内不写测试计数以外的易漂移事实；计数以 `docs/generated/test-inventory.md` 为准。
4. 旧报告冻结；勘误在文首注明日期与范围，不静默改写历史。
