# MiniLang IDE 常见问题 FAQ

本 FAQ 按主题分组，覆盖新手最常遇到的问题。详细语法差异请参见 [language-comparison.md](./language-comparison.md)，核心架构请参见 [architecture.md](./architecture.md)。

---

## 代码编写

### Q1: 为什么 `f(); fun f() {}` 会报错？

MiniLang **没有函数提升**——函数必须先声明后使用。`f();` 执行时 `f` 还未在作用域中绑定，会报「未定义的函数」。这与 Python（`def` 执行到才绑定）和 Java（类成员可前向引用）都不同，更接近 C 的严格顺序声明。把 `fun f() {}` 移到调用之前即可。

### Q2: 为什么 `var b = a; b.push(4);` 后 `a` 也变了？

数组与字典采用 **COW（Copy-On-Write）**：`var b = a;` 时 `b` 与 `a` **共享**底层数据，只有当 `b` 被**修改**且不独占所有权时才触发深拷贝。若 `a` 之后不再被使用并被回收，`b` 独占所有权时 `b.push(4)` 不会复制，此时 `a`（如果还存活）也会受影响。需要独立副本请显式构造新数组，不要依赖赋值语义。

### Q3: 为什么 `print(1 / 2);` 输出 `0` 不是 `0.5`？

MiniLang 的 `/` 对两个 `int` 操作数执行**截断向零**的整数除法（C 风格），三后端语义统一。这与 Python 的 `/`（始终浮点）不同。要浮点结果，至少一个操作数须为 `float`：`1.0 / 2` 得 `0.5`。

### Q4: 为什么 `if (a and b)` 返回的不是 `true/false`？

`and` / `or` 短路求值后**返回操作数原值**（非布尔），与 Python 一致，与 C/Java（返回 `bool`）不同。例如 `0 or "x"` 得 `"x"`，`1 and 2` 得 `2`。`if` 判断基于「真假性」所以没问题，但若把结果存入变量当布尔用会踩坑。需要布尔结果用 `not not (a and b)`。

### Q5: 如何写匿名函数？

**MiniLang 不支持匿名函数表达式**。`var f = fun() {};` 会被解析器拒绝（报「意外的 Token: 'fun'」）。正确写法是用**命名函数声明**再传递引用：

```mini
fun _myCallback(x) { print(x); }
var f = _myCallback;       // 命名函数本身是一等值
[1, 2, 3].forEach(_myCallback);
```

闭包同样必须用具名嵌套函数：`fun outer() { var x = 1; fun inner() { return x; } return inner; }`。

### Q6: 如何创建多行字符串？

MiniLang **没有专门的多行字符串语法**（不支持 Python 三引号 / Java 文本块之类的写法）。可用字符串拼接或数组 `join` 实现：

```mini
var s = "line1\n" +
        "line2\n" +
        "line3";
print(s);

// 或用数组 join
var lines = ["line1", "line2", "line3"];
print(lines.join("\n"));
```

字符串内的 `\n` 转义符会被解释为换行。

## 运行调试

### Q7: 三后端（解释器 / 栈 VM / 寄存器 VM）什么时候该用哪个？

- **树遍历解释器**：调试、REPL 交互、教学时看清 AST 执行过程。支持完整断点 / 单步 / 变量监视 / 调用栈。
- **栈式 VM**：通用执行、字节码可视化。操作数栈 push/pop 可视化便于理解栈式虚拟机原理。
- **寄存器式 VM**：性能对比、IR 研究。32 虚拟寄存器 R0-R31，IR 三地址码直接 lowering。

调试优先选解释器；学字节码选栈 VM；学 IR 与寄存器分配选寄存器 VM。状态栏右侧实时显示当前引擎。

### Q8: 如何设置条件断点？

在编辑器行号区点击设置普通断点，然后**右键断点行** → 「编辑断点条件」，输入条件表达式（如 `i == 5` 或 `x > 100`）。条件求值在沙箱中隔离执行，不会污染程序状态。也可打开「条件断点可视化面板」（视图菜单）查看所有断点的条件与命中次数。命中次数累加显示。

### Q9: 如何查看当前调用栈？

打开「调用栈可视化面板」（视图菜单）。面板优先走 VM 路径（`getVmCallStack()`），回退到解释器 debug 路径，500ms 自动刷新，显示栈帧列表（函数名 / 行号 / 深度 / 本地变量）。**点击栈帧会自动跳转到对应源码行**（M5 功能），与 VS Code / CLion 调试器行为一致。

### Q10: REPL 中如何查看 AST / IR / 字节码？

在 REPL 输入 `%` 前缀的 magic 命令即可调用各面板的数据获取逻辑：

| 命令 | 作用 |
|------|------|
| `%ast` | 显示最近执行的 AST（同 AstViewer 面板） |
| `%ir` | 显示当前输入 / 最近执行的 IR（同 IrViewer） |
| `%tokens` | 显示最近的 Token 表（同 PipelineViewer Step 1） |
| `%disassemble` | 显示最近执行的字节码（同 BytecodeTracePanel） |
| `%compare` | 运行三后端对比 |
| `%profile` | 显示指令计数热点 |
| `%memory` | 显示当前堆对象统计 |
| `%help` | 列出所有 magic 命令 |
| `%version` | 显示 MiniLang 版本信息 |
| `%reset` | 重置 VM 状态（清除所有变量 / 函数） |

也可直接打开对应面板（视图菜单）查看持久可视化。

### Q11: 如何对比三后端的执行结果？

打开「三后端并行对比面板」（Ctrl+Shift+B），或 REPL 输入 `%compare`。面板会顺序运行 Interpreter / StackVM / RegisterVM 三条路径，每路径独立计时（微秒精度）+ 输出比对，自动统计行级差异并给出一致性 PASS/FAIL 结论。三后端输出一致即「三后端语义等价」教学验证。

## 教学面板

### Q12: 21 个教学面板从哪里开始看？

推荐路径：先打开「**学习路径地图面板**」（视图菜单，或 Ctrl+Shift+L 打开学习中心），按 5 阶段渐进式学习——阶段零「首次接触」全部无前置解锁，从 welcome 导览 / code-journey 信息图 / token-puzzle 拼图开始。完成前置活动后自动解锁后续。也可直接看「代码生命旅程信息面板」了解从源码到输出的完整管线，再按兴趣跳转。

### Q13: 如何打开学习路径地图？

视图菜单 → 「学习路径地图」，或 ActivityBar 左侧「学习」入口（EDUCATION 图标）→ 弹出学习中心对话框选择活动。学习路径地图是中央导航枢纽，将所有教学面板与 28 个学习活动组织为 5 阶段（首次接触 / 编译前端 / 执行引擎 / 深入理解 / 实战训练），共 21 个教学面板。进度自动持久化（JSON 文件），无前置条件限制可自由访问。

### Q14: BugHunt 的难度分级是什么意思？

Bug 狩猎面板题库分三级：
- 🟢 **入门级**（5 道）：阅读理解型，预测输出 / 块作用域 / Formatter 展开 / 循环 var / COW refCount。
- 🟡 **进阶级**（4 道）：BUG-DEF / REGVM / REPL / Formatter。
- 🔴 **专家级**（6 道）：IR-POP / 条件断点 / 闭包 upvalue / 调试 / 模块等历史真实 Bug。

每题含背景 / 源码 / 期望行为 / Bug 行为 / 递进提示 / 根因分析。三档必须按顺序通关（前置依赖）。默认显示入门级，可用难度筛选栏切换。第五档新增「三后端对比」按钮与 7 个变体挑战题。

### Q15: Token 拼图游戏有几关？

**5 关**，由浅入深：
1. `var x = 42;` — 基本 5 个 token（⭐）
2. `print("hello");` — 字符串是一个 token 而非 7 个（⭐）
3. `x > 0 and y < 10;` — 运算符优先级不影响 token 切分（⭐⭐）
4. `// 注释\nprint(1);` — 注释被分离出主流（⭐⭐）
5. `a[0] = b["key"] + 1;` — 复杂表达式 12 个 token（⭐⭐⭐）

星级评分：0 次提示 = ⭐⭐⭐，1 次 = ⭐⭐☆，2+ 次 = ⭐☆☆，跳过 = ☆☆☆。完成或跳过当前关后自动解锁下一关。

### Q16: AST 搭建玩具有几道题？VM 栈沙盒有几关？

- **AST 搭建玩具**：6 道题（`42` / `1+2` / `1+2*3` / `(1+2)*3` / `print(x)` / `var x=1+2;`）。核心教学时刻是题 3 vs 题 4——同样数字与运算符，仅括号不同就导致完全不同的 AST 结构。
- **VM 栈沙盒**：5 关（`1+2` / `1+2*3` / `(1+2)*3` / `"hello"` / 自由模式）。核心教学时刻是关 2 vs 关 3——同指令集不同执行顺序得不同结果（7 vs 9）。

## IDE 操作

### Q17: 如何修改字号？

代码编辑器：`Ctrl + =` 放大、`Ctrl + -` 缩小、`Ctrl + 0` 还原（CodeEditor::changeFontSize）。实验手册面板有独立的字号 SpinBox（8-24pt 可调）。字号设置作用于当前编辑器与手册内容。

### Q18: 如何切换主题（深色 / 亮色）？

点击**标题栏的主题切换按钮**（CONSTRACT 图标，亮色显示月亮 / 暗色显示太阳）。主题选择持久化到 QSettings（`theme_mode` 字段，默认 light），下次启动自动恢复。切换后所有面板（含教学面板的 QSS、HTML 内容、滚动条样式）会跟随刷新。

### Q19: 快捷键列表在哪里看？

主要快捷键：
- **运行 / 调试**：工具栏运行按钮
- **查找替换**：Ctrl+F（查找）/ Ctrl+H（替换）
- **跳转行**：Ctrl+G
- **注释切换**：Ctrl+/（行注释）
- **选中相同词**：Ctrl+D（单光标简化版）
- **删除当前行**：Ctrl+Shift+K
- **多行缩进**：Tab / Shift+Tab
- **字号**：Ctrl+= / Ctrl+- / Ctrl+0
- **教学面板**：Ctrl+Shift+P（编译管线）/ Ctrl+Shift+B（三后端对比）/ Ctrl+Shift+H（Bug 狩猎）/ Ctrl+Shift+S（语法探索器）/ Ctrl+Shift+L（学习中心 / 实验手册）

编辑器右键上下文菜单也提供注释切换 / 块注释 / 格式化 / 跳行 / 查找替换 / 断点切换 / 编辑断点条件 / 运行到光标等操作。

### Q20: 如何重置 IDE 布局？

教学面板默认隐藏，通过视图菜单（已重构为 4 子菜单 + 学习中心入口）切换显隐。每个 dock 面板可拖动重排、关闭、重新打开。布局会自动保存（dock 状态防抖保存）。若布局混乱，可逐个从视图菜单重新打开需要的面板；教学面板统一有「这是什么？」与「学习路径」标题栏按钮辅助导航。首次用户完成欢迎向导后会自动展开「学习路径地图面板」作为起点。

### Q21: 拖放文件到 IDE 不工作怎么办？

IDE 支持从 Windows 资源管理器等外部拖入 **`.mini` / `.ml` 文件**到窗口任意区域（已打开则切换标签，否则新开标签加载）。若不工作，请检查：
1. 文件扩展名是否为 `.mini` 或 `.ml`（其他扩展名会被忽略）。
2. 是否拖到了 IDE 窗口区域（非对话框遮盖区域）。
3. 也可用「文件 → 打开」或文件树右键「在文件资源管理器中显示」替代。

外部编辑器修改当前打开的文件时，IDE 会弹框询问是否重新加载（支持 Vim「删除+重建」文件模式）。
