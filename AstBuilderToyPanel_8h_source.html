1// ============================================================
2// AstBuilderToyPanel.h — AST 节点搭建玩具面板（功能 4）
3// ------------------------------------------------------------
4// 通过点击/组装 AST 节点，让学习者理解「AST 是代码的结构化表示」。
5// 6 道题由浅入深，核心教学时刻：第 3 题 vs 第 4 题——同样数字和运算符，
6// 仅括号不同就导致完全不同的树结构（优先级 vs 括号改变结构）。
7//
8// UI 布局：
9// 顶部：QComboBox（题目选择）+ QLabel（进度：N/6 已完成）
10// 主体（左右分栏）：
11// 左侧：节点工具箱（QPushButton 列表：Number / Add / Sub / Mul / Div /
12// Print / VarDecl）
13// 右侧：QTreeWidget（已搭建的 AST 树，支持选中/删除）
14// 底部：[✓ 检查] [👁 查看标准答案] [➡ 下一题] [🔄 清空] [🗑 删除节点] +
15// QLabel 反馈区 + QLabel 题目说明
16//
17// 交互逻辑（简化版，不要求复杂拖拽）：
18// - 点击工具箱节点：
19// * 若 QTreeWidget 当前无选中项 AND 树为空 → 添加为根节点
20// * 若 QTreeWidget 当前无选中项 AND 树非空 → 反馈提示先选中父节点
21// * 若 QTreeWidget 当前有选中项 → 添加为选中项的子节点
22// - 节点工具箱中：Number / VarDecl 需要弹 QInputDialog 输入值/名称；
23// Add / Sub / Mul / Div / Print 直接创建对应标签节点
24// - 选中节点 + Delete 键 / 「删除节点」按钮：移除该节点（及其子树）
25// - 检查答案：递归比对玩家树与 answer 树的拓扑结构（label + children 顺序）
26// - 查看标准答案：将 answer 树渲染到 QTreeWidget（覆盖当前内容）
27// - 下一题：切换 QComboBox 到下一题，清空画布
28// - 清空：移除画布所有节点
29//
30// 信号：
31// activityCompleted(levelId) — 完成某题（检查通过）时发射，
32// levelId 格式为 "ast-toy-level-N"（N=1..6），供 LearningPathPanel
33// 标记活动完成使用。
34//
35// 关键架构决策：
36// - 使用 QTreeWidget 而非 QGraphicsScene，实现简单、测试容易
37// - AstBuilderToyPanel.cpp 依赖 Qt6::Widgets，不加入测试目标
38// （与 LearningPathPanel.cpp 设计模式一致）
39// - 静态数据放在 AstToyLevels.cpp 独立编译单元，测试目标可单独链接
40// - 不依赖 IdeController / Lexer / Parser / Interpreter，纯前端游戏
41// - 所有用户可见文本用 mlTr() 包裹（i18n）
42// ============================================================
