4// CourseSystemPanel — 教学课程系统面板
5// ------------------------------------------------------------
6// 可自定义的课程内容管理面板，用 JSON 格式（QJsonDocument）描述
7// 章节 / 关卡 / 任务 / 答案校验。与 LearningPathPanel（学习路径

9// - LearningPathPanel：固定 5 阶段 21 活动的进度跟踪
10// - CourseSystemPanel：可自定义的课程内容管理（3 个预设课程
11// + 用户自定义 JSON 课程）
12//
13// 两个子页：
14// 1. 课程库：QComboBox 选择预设/自定义课程，QTextBrowser 展示
15// 课程大纲（章节/关卡/任务/知识点），可加载课程代码到编辑器
16// 2. 课程编辑器：QTextEdit 编辑课程 JSON，解析预览后可加载到
17// 课程库下拉框
18//
19// 拓展二期·课程内容外部化：
20// - 从磁盘 JSON 文件导入课程（编辑器子页「从文件导入」）
21// - 导出当前选中课程到 JSON 文件（课程库子页「导出课程」，
22// 预设课程也可导出作为编写模板；配合 minilang-pkg 可作为
23// 课程包分发：pkg 包目录放 course.json，学生导入即用）
24// - 自定义课程 QSettings 持久化（重启 IDE 不丢失）
25//
26// 设计约束：
27// - 面板构造函数不创建标题栏（Ide::wrapTeachingPanel 自动包裹）
28// - setController 内联实现（仅赋值，面板不依赖控制器运行）
29// - 纯教学面板，不运行执行引擎，expectedOutput 只展示不校验
30// - 用 QJsonDocument 解析 JSON，不引入第三方 YAML 依赖
31// - 不使用 C++20 关键字 concept 作为字段名
32// - 字符串字面量中不使用中文引号 “”，用「」替代
33// ============================================================
