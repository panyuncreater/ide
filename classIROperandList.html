Detailed Description

指令操作数容器：≤4 个操作数内联存储免堆分配，超出回落堆缓冲。 第四轮优化：原 std::vector<IROperand> 使每条 IRInstruction 携带一次独立 堆分配（IR 构建 / pass 复制 / lowering 全链路），绝大多数指令操作数 ≤4 个（LOAD_CONST/BINOP/JUMP/STORE_LOCAL 等），内联后零分配且提升 局部性（操作数与指令同处缓存行）。IROperand 为平凡可复制类型， 实现按 memcpy 语义复制，无元素级构造/析构分叉。

接口刻意收敛到 IR 层现有使用面（size/empty/operator[]/push_back/ 迭代/initializer_list 赋值），不实现完整 vector 接口——新调用点若 需要 erase/insert 等能力应先评估是否真适用于 IR 操作数语义。
