3// ============================================================
4// StepExplainerPanel — 执行步骤讲解生成器教学面板
5// ------------------------------------------------------------
6// 为每条字节码指令生成自然语言讲解，帮助学习者理解栈式 VM 的
7// 指令格式、操作数编码、栈效果与语义。面板内部独立完成
8// Lexer → Parser → Compiler 流程（不依赖 IdeController）。

10// 两个子页：
11// 1. 指令讲解生成器：源码输入 + 编译 + 字节码列表（步骤/IP/OpCode/讲解摘要）
12// + 选中指令的详细讲解（HTML：指令名/操作数值/栈效果/语义/源码行号）
13// 2. OpCode 分类速查：82 个 OpCode 按分类分组列表 + 选中 OpCode 详细语义
14//
15// 本面板仅消费自带 StepExplainerLibrary 静态文档库 + 面板内编译产物，
