处理数组内置方法（push, pop, len, remove, contains, join）

Parameters
method方法名
obj数组值（可变引用，push/pop/remove 会修改）
args已求值的参数列表
line调用行号（用于错误报告）
col调用列号（用于错误报告）
Returns
方法结果 + 是否修改了对象
Exceptions
RuntimeError参数错误或方法不存在时

分发数组内置方法。 设计：变异方法（push/pop/remove）直接就地修改 obj，返回 objectModified=true 以便调用方（Interpreter/VM）知道原对象已变更、无需再取返回值；非变异方法 （len/contains/join）通过 arraySharedMethods() 注册表委托共享纯函数实现， 统一经 dispatchShared 将 Result<Value> 转为 BuiltinMethodResult 或抛 RuntimeError。 未知方法名抛出 RuntimeError。方法名由 classifyBuiltinMethod 预先分类。

处理字典内置方法（len, keys, values, has/contains, get, remove）

分发字典内置方法。 变异方法（remove/set）直接就地修改 obj 的 entries；has/contains 因共享层 executeSharedDictHas 需要 method 名用于错误消息而单独特判；其余（len/keys/values/get） 委托 dictSharedMethods() 共享实现。未知方法名抛出 RuntimeError。

处理字符串内置方法（len, upper, lower, split, replace, trim） 字符串是不可变的，所以 obj 为 const 引用

分发字符串内置方法。 字符串方法均为非变异（返回新字符串，不改原串），因此 obj 以 const 引用传入。 全部通过 stringSharedMethods() 注册表委托共享纯函数实现；contains 已在注册表中， 无需内联特例。未知方法名抛出 RuntimeError。
