3// ============================================================
4// BytecodeCache — P1-7: 字节码磁盘缓存
5// ------------------------------------------------------------
6// 将 CompileResult 序列化为二进制文件,下次同源码命中时跳过编译。
7//
8// 缓存 key = FNV-1a(source) + compilerMode。
9// - source 变化 → hash 变化 → 自动失效
10// - compiler 模式切换(direct/IR)→ compilerMode 不同 → 自动隔离
11//
12// 二进制格式:
13// [Header 32B]
14// magic[4] = "MLBC" (StackVM) 或 "MLRC" (RegisterVM, L11)
15// format_version(u16) = 1
16// compiler_mode(u8) 0=直接 codegen, 1=IR 路径
17// reserved(u8) = 0
18// source_hash(u64) FNV-1a 64bit of source
19// source_mtime(i64) 源码 mtime(毫秒,0=不校验)
20// payload_checksum(u32) FNV-1a 32bit of payload
21// payload_size(u32)
22// [Payload]
23// CompileResult 或 RegisterCompileResult 序列化数据(见 .cpp 序列化函数)
24//
25// 安全保证:
26// - magic/version/compiler_mode/hash/checksum 五重校验,任一不匹配返回 nullopt
27// - L13 扩展：Value 支持标量(int/float/bool/null/string) + 容器堆类型
28// (array/dict/tuple/enum_variant)，递归序列化元素 + 环检测
29// - 不可序列化类型(closure/instance/channel/mutex/rwlock/thread/coroutine)
30// 标记为 kNonSerializableTag 使反序列化失败,安全降级到正常编译
31// - 所有越界/截断/类型错误均返回 nullopt,不抛异常
32//
33// 已知限制:
34// - REPL 路径不走 Compiler,无法受益
35// - 注：当前编译器 addConstant 调用点仅放入标量，L13 的容器堆类型序列化为
36// 防御性支持（应对未来 IR 常量折叠扩展可能产生 array/dict 常量）
37//
38// L12 预编译模块源码失效校验（2026-07-24）:
39// - storeToFile 接受可选 sourcePath,写入源码 mtime + content hash 到头部
40// - tryLoadFromFile 接受可选 sourcePath,加载时校验源码 mtime+hash,
41// 不匹配返回 nullopt（源码已修改,.minic 失效,回退源码编译）
42// - 向后兼容:旧 .minic 头部 source_mtime=0 自动跳过校验
43//
44// L13 容器堆类型常量序列化（2026-07-24）:
45// - writeValue/readValue 扩展支持 Array/Dict/Tuple/EnumVariant
46// - BoxedInt（超 int48 范围）自动通过 isInt() 路径处理
47// - 环检测：thread_local visited 集合记录已访问堆对象指针
48// - isSerializable 改为递归检查（含环检测）
49//
50// L11 RegisterVM 预编译模块支持（2026-07-24）:
51// - 新增 storeRegisterToFile / tryLoadRegisterFromFile 文件级 API
52// - 使用独立 magic "MLRC"（MiniLang Register Cache）与 StackVM "MLBC" 隔离
53// - 头部布局相同（32B），仅 magic 不同，复用 L12 mtime+hash 校验
54// - RegBytecodeChunk 序列化字段：比 BytecodeChunk 多 registerCount 字段，
55// localRegNames 对应 localSlotNames
56// - RegisterCompileResult 序列化字段：含 moduleExports（L11 新增）
57//
58// L17 PipelineRunner 内存级 RegisterVM 缓存（2026-07-24）:
59// - 新增 tryLoadRegister(CacheKey) / storeRegister(CacheKey, RegisterCompileResult) 内存级 API
60// - 与 tryLoad/store 对称：基于源码 hash 的缓存查询，使用 `.mrc` 扩展名
61// - 与 L11 文件级 API 区别：L11 是 .minic 路径-based（模块预编译），
62// L17 是 source hash-based（PipelineRunner 主程序编译缓存）
63// - PipelineRunner.runCompiler 检测 useRegisterVM_，RegisterVM 路径走 register 缓存
64// ============================================================
