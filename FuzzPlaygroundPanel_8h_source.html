3// ============================================================
4// FuzzPlaygroundPanel — 模糊测试游乐场教学面板
5// ------------------------------------------------------------
6// 交互式展示 R164 模糊测试的三后端差分验证。复用 cli/fuzz_core.h
7// 的公开 API（fuzzThreeAgree / runFuzzBatch / formatSummaryText），
8// 支持三种模式：
9// (1) 单次差分：输入源码立即三后端对比
10// (2) 批量生成：基于种子模板化随机生成 N 段程序后统计
11// (3) 批量变异：对种子语料做字节级变异 N 次后统计
12//
13// 单页设计（不使用子页切换）：
14// - 顶部：QTextEdit 源码编辑器（多行，默认填入样例）
15// + 模式切换 QComboBox（单次差分 / 批量生成 / 批量变异）
16// + 运行按钮 + QSpinBox 种子（0-999999，默认 42）
17// + QSpinBox 迭代次数（1-200，默认 20，仅批量模式）
18// + 加载样例按钮
19// - 中间：QSplitter(Vertical)
20// 上方 QTabWidget（3 个标签页）
21// Tab1 差分结果：QTableWidget
22// 单次模式 3 行 Interpreter/StackVM/RegisterVM
23// 4 列 后端/输出/状态/耗时
24// 批量模式 1 行汇总
25// 6 列 总次数/一致/分歧/崩溃/解析失败/运行时错误
26// Tab2 分歧详情：QTableWidget
27// 3 列 序号/源码片段/分歧类型（仅批量模式有数据）
28// Tab3 统计报告：QTextBrowser HTML 报告
29// （差分摘要 + 错误归一化说明 + 教学解释）
30// 下方 QTextBrowser 选中项详情
31// （选中差分结果行或分歧行后展示完整源码+三后端输出对比 HTML）
32// - 底部：QLabel 一致性提示（"✅ 三后端一致 N 次" / "❌ 发现 M 个分歧"）
33// + 加载源码到主编辑器按钮
34//
35// 设计约束：
36// - 面板构造函数不创建标题栏（Ide::wrapTeachingPanel 自动包裹）
37// - setController 内联实现（仅赋值，不注册监听器）
38// - 批量模式在主线程串行执行（runFuzzBatch 阻塞调用，教学面板可接受；
39// 不放到 Worker 线程避免复杂化）
40// - 批量模式迭代次数上限 200（避免 UI 卡死太久）
41// - 分歧用例最多展示前 20 个（disagreementCases 上限 50）
42// ============================================================
43
