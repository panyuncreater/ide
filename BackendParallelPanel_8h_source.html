3// ============================================================
4// BackendParallelPanel — 三后端并行可视化教学面板
5// ------------------------------------------------------------
6// 在面板内独立完成 Interpreter / StackVM(IR) / RegisterVM(IR)
7// 三个后端执行同一份源码的状态对比，让学习者直观验证三后端
8// 语义等价性。面板内部独立完成 Lexer → Parser → 各后端执行
9// 流程（不依赖 IdeController），参考 TestNestedLvalueProbe.cpp
10// 的 runInterp / runStackVM_IR / runRegVM_IR 辅助函数模式。
11//
12// 单页设计：
13// - 顶部：QLineEdit 源码输入 + 运行按钮 + 3 个内置样例切换
14// - 中间：QSplitter(Vertical)
15// 上方 QTableWidget(5 列: 后端/输出/指令数/状态/耗时ms)
16// 下方 QSplitter(Horizontal) 三个 QTextBrowser 详细执行轨迹
17// - 底部：加载样例到主编辑器按钮 + 一致性提示标签
18//
19// 设计约束：
20// - 面板构造函数不创建标题栏（Ide::wrapTeachingPanel 自动包裹）
21// - setController 内联实现（仅赋值，不注册监听器）
22// - 三后端在主线程串行执行（避免引擎层非线程安全问题）
23// ============================================================
