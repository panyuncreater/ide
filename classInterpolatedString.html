Detailed Description

C5 fix: 插值字符串节点 — 保留 "text {expr} more {expr2}" 的 AST 结构 原 parseInterpolatedString 将其抹平为 BinaryOp(BIN_ADD) 链，Formatter 无法 重建插值语法，AstViewer 只能看到一堆 BinaryOp。本节点存储交替的字面量片段 和表达式，Formatter 可精确重建 "text {expr} more {expr2}" 语法。
