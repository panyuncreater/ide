3// ============================================================
4// MarkdownRenderer.h — 轻量 Markdown → HTML 渲染器（教学面板共用）
5// ------------------------------------------------------------
6// 用于把教学面板的散文式说明文本统一渲染为 QTextBrowser 可显示的 HTML，
7// 替代各面板手写的 "<p><b>...</b></p>" 模板字符串。
8//
9// 支持的 Markdown 子集（覆盖 LabManualContent.cpp + 各 Library 散文字段）：
10// - 标题：# / ## / ### / #### / ##### / ######
11// - 粗体：**text**
12// - 斜体：*text*
13// - 行内代码：`code`
14// - 围栏代码块：```lang\n...\n```（lang 作为语言标签显示在代码块上方）
15// - 无序列表：- / * 开头
16// - 有序列表：1. / 2. 开头
17// - 任务列表：- [ ] / - [x] 开头（渲染为带复选框的列表项）
18// - 引用块：> text（渲染为带左边框的引用块）
19// - 表格：| col1 | col2 | + 分隔行 |---|---|
20// - 水平分割线：--- / ***（单独成行）
21// - 段落：空行分隔
22//
23// CSS 样式注入：输出 HTML 包含 <style> 块，让标题/列表/代码块/表格/引用块
24// 有美观的视觉效果（颜色、间距、圆角、边框等），无需调用方额外加样式。
25//
26// 不依赖第三方库，单遍扫描实现，~400 行。
27// ============================================================
