Detailed Description

VM 调用栈帧条目（IVmBackend::getCallStack 返回类型） StackVM 与 RegisterVM 共享同一结构：函数名 + 当前行号 + 指令指针。 不含 locals（需通过具体子类的 getFrameLocalsAt 单独查询，避免每个后端 自行实现 locals 反查逻辑）；不含 depth（调用方按 vector 索引推导）。
