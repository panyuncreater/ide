Detailed Description

B1 TCO：自尾调用信号——visitReturnStmt 识别 return f(args) / return this.m(args) 自尾调用后抛出（携带已求值的实参），由 callNamedFunction / invokeMethod 的蹦床循环捕获并帧复用执行， 使深尾递归在恒定 C++ 栈深内完成（对齐 StackVM/RegisterVM 的 TCO）。 不是错误：仅在 TCO 上下文启用（tcoEnabled_）且不在 try 块内时抛出， 非蹦床的函数体执行点（init/生成器/闭包变量/高阶回调）显式禁用上下文， 保证信号不会逃逸出对应的蹦床边界。
