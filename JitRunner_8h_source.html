3// ============================================================
4// JitRunner — JIT 运行隔离层（Qt ↔ asmjit 冲突解耦）
5// ------------------------------------------------------------
6// 问题：compiler/jit/JIT.h 包含 <asmjit/asmjit.h>，asmjit 的标识符
7// （InstId/inst_id 等）与 Qt 头文件拉入的 Windows 宏冲突，导致
8// 同时包含 Qt 头与 JIT.h 的编译单元解析失败。
9//
10// 方案：JitRunner 是纯 C++ 桥接层（不包含任何 Qt 头），封装
11// "Lexer→Parser→Compiler→JITBackend→采集 getter" 全流程，返回
12// STL 数据结构。GUI 面板（JitVisualizerPanel）只包含本头文件，
13// 不直接包含 asmjit，彻底回避冲突。
14//
15// 线程安全：runTypeFeedback/runHotspot 在 UI 线程同步执行 JIT
16// （示例代码小，毫秒级）。JITBackend 为局部实例，execute 返回后
17// 读 getter，无并发。
18// ============================================================
