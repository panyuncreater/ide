5// ------------------------------------------------------------
6// 可视化 GcManager 的 mark-sweep-finalize 三阶段垃圾回收流程、
7// 三种 GcMode（RefCountOnly / RefCountWithCycleGc / GcOnly）、

9//
10// 纯教学/模拟面板（不运行执行引擎），但实时读取 GcManager 单例统计。

12// 两个子页：
13// 1. GC 原理与三阶段流程：HTML 文档 + 阶段表 + GcMode 对比表 + 容器注册表

15// + 实时统计表 + 模拟过程 HTML
16//
17// 设计约束：
18// - 面板构造函数不创建标题栏（Ide::wrapTeachingPanel 自动包裹）

20// - 纯教学/模拟面板，不运行任何执行引擎
