Detailed Description

字面量类型检查遍历器。在编译期为带类型注解的变量声明/赋值做"字面量 vs 注解" 的一致性检查：仅当初始化器是字面量（NumberLiteral/StringLiteral/BoolLiteral/NullLiteral） 时才能静态判定类型，非字面量表达式交由运行时 OP_TYPE_CHECK 处理。 通过 varTypes 表在作用域间传播注解；visit* 各语句对块/分支/循环/函数体 使用"保存-恢复"模式隔离作用域，避免内层注解污染外层（AUDIT-BUG-E1）。

检查单个变量声明的字面量类型匹配。 无注解或无初始化器时仅登记注解供后续 Assignment 复用； 否则用 dynamic_cast 判定初始化器字面量类型，与注解比对，不匹配则发警告。 NullLiteral 兼容任何注解（视为通过）。最终把注解写入 varTypes。

static bool minilang::LiteralTypeWalker::typeMatchLiteral ( const std::string &  actual,
const std::string &  annotation 
)
inlinestaticprivate

判断字面量实际类型 actual 是否兼容类型注解 annotation。 规则：无注解→兼容；int 注解只接受 int；float 注解接受 float 与 int（int 可提升）； bool/string 严格匹配；array/dict/类名等无法在字面量层面判定→保守返回兼容 （避免误报，交由运行时检查）。返回 false 时调用方发警告。
