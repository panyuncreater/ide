213// R98 W2: 高阶函数共享层（map / filter / reduce / forEach / find）
214// ============================================================
215// 这 5 个高阶函数需要调用用户传入的闭包值。由于 executeSharedBuiltinFunction
216// 是无状态纯函数层（无法调用闭包），此处提供独立的共享算法层：
217// 各后端（Interpreter / StackVM / RegisterVM）注入 ClosureInvoker 回调
218// 实现闭包调用，算法本身（数组遍历、结果构建）三后端共享。
219//
220// 设计要点：
221// 1. 闭包调用是后端特定的（Interpreter 用 AST eval，VM 用帧压栈+run loop，
222// RegisterVM 用寄存器帧+run loop），无法在共享层实现
223// 2. 算法逻辑（遍历、过滤、归约）与后端无关，抽取到共享层避免 3x 重复
224// 3. 与 input() 类似，各后端在调用 executeSharedBuiltinFunction 之前拦截
225// 这 5 个名字，分派到本共享层
226
