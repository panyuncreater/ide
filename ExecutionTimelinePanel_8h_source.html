3// ============================================================
4// ExecutionTimelinePanel — 可回放执行时间轴面板（R114 阶段 1）
5// ------------------------------------------------------------
6// 三后端统一的执行轨迹回放面板。订阅 traceRecorder() 全局单例，
7// 录制期间定时刷新步骤列表，用户可通过 QSlider / 步进按钮 / 列表点击
8// 随机访问任意步快照，右侧详情区显示栈 / locals / globals / callStack。
9//
10// 三后端支持：
11// - Interpreter：AST 节点级（opOrNodeName = "IfStmt" / "BinaryOp" 等）
12// - StackVM：字节码级（opOrNodeName = "OP_ADD" / "OP_CALL" 等）
13// - RegisterVM：寄存器指令级（opOrNodeName = "REG_ADD" 等）
14//
15// 与 BytecodeTracePanel 的区别：
16// - BytecodeTracePanel 仅 VM 路径 + 仅 1000 条 + 仅栈快照
17// - 本面板三后端统一 + 5000 条环形缓冲 + 完整快照（栈/locals/globals/callStack）
18// - 本面板支持随机访问任意步（BytecodeTracePanel 仅顺序追加）
19//
20// 不依赖 IdeController（直接用 traceRecorder() 单例），可独立测试。
21// 仅在录制时通过 setBackendType() 告知面板当前后端类型，用于显示标签。
22// ============================================================
23
