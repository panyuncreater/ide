3// ============================================================
4// PerformanceRacePanel — 三后端性能竞赛教学面板
5// ------------------------------------------------------------
6// 在面板内独立完成 Interpreter / StackVM(IR) / RegisterVM(IR)
7// 三个后端执行同一份源码的性能对比，让学习者直观理解三后端
8// 性能差异。每个后端运行 N 次（1-10，默认 5），记录平均/最小/
9// 最大耗时，并用 HTML/CSS 绘制水平柱状图可视化对比。
10//
11// 与 backend-parallel 面板互补：
12// - backend-parallel 侧重「执行轨迹文本对比」
13// - 本面板侧重「性能数据可视化（柱状图）+ 多次运行取平均
14// + 性能分析报告」
15//
16// 单页设计（不使用子页切换）：
17// - 顶部：QLineEdit 源码输入 + 运行次数选择（QSpinBox 1-10）
18// + 竞赛按钮 + 3 个内置样例切换（基本算术/递归fib/循环累加）
19// - 中间：QSplitter(Vertical)
20// 上方 QTableWidget 性能对比表（5列：后端/平均/最小/最大/指令数）
21// 行：Interpreter / StackVM(IR) / RegisterVM(IR)
22// 中间 QTextBrowser 柱状图（HTML/CSS 水平柱状图）
23// 下方 QTextBrowser 性能分析报告
24// - 底部：加载样例到主编辑器按钮 + 一致性检查标签
25//
26// 设计约束：
27// - 面板构造函数不创建标题栏（Ide::wrapTeachingPanel 自动包裹）
28// - setController 内联实现（仅赋值，不注册监听器）
29// - 三后端在主线程串行执行（避免引擎层非线程安全问题）
30// - 每个后端运行 N 次（运行次数由 QSpinBox 选择），取平均/最小/最大
31// - 复用 BackendParallelPanel.cpp 的三后端执行模式（Compiler
32// setUseIR(true) / setUseRegisterVM(true) 触发 IR 路径）
33// ============================================================
