3// ============================================================
4// CoroutineVisualizerPanel — 协程/生成器可视化教学面板
5// ------------------------------------------------------------
6// 可视化 MiniLang 协程/生成器（fun* / yield / .next() / .done()）
7// 在 Interpreter / StackVM(IR) / RegisterVM(IR) 三条后端路径上的
8// yield 重放机制与语义等价性。JIT 后端暂不支持协程，按钮文案
9// 标注「运行四后端」但实际执行三后端（与 BackendParallelPanel 一致）。
10//
11// 面板内部独立完成 Lexer → Parser → 三后端执行流程，复用
12// BackendParallelPanel 的 runInterpreter / runStackVM_IR / runRegVM_IR
13// 辅助函数模式，并在表格与执行轨迹中额外展示协程状态摘要
14// （yield 序列、done 终止态、生成器 chunk 的 isGenerator/yieldCount）。
15//
16// 单页设计：
17// - 顶部：QLineEdit 源码输入 + "运行四后端"按钮 + 样例 QComboBox
18// - 中间：QSplitter(Vertical)
19// 上方 QTableWidget(5 列: 后端/输出/状态/协程状态/耗时ms)
20// 下方 QSplitter(Horizontal) 三个 QTextBrowser 详细执行轨迹
21// - 底部：加载样例到主编辑器按钮 + 一致性提示标签
22//
23// 设计约束：
24// - 面板构造函数不创建标题栏（Ide::wrapTeachingPanel 自动包裹）
25// - setController 内联实现（仅赋值，不注册监听器）
26// - 三后端在主线程串行执行（避免引擎层非线程安全问题）
27// - 字体使用 GuiTextUtils::monospaceFont(N) 工厂
28// - 显示字符串用 mlTr() 包裹（注册时由 PanelCatalog 标注）
29// ============================================================
