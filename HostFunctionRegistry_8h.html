Detailed Description

七特性 MVP 阶段 7：宿主函数注册表——插件/嵌入方注册的原生 C 函数。

设计：

  • core 层中立类型 HostValue（tagged union：null/bool/int64/double/utf8 string）， 避免 core 反向依赖 capi 头（capi 依赖 core）。
  • HostFn = HostValue(*)(const HostValue* args, int argc, void* userdata)。
  • 全局单例注册表（name → fn+userdata），三后端在"未定义函数"回退路径查表调用。
  • Value ↔ HostValue 转换器仅支持 5 种标量（容器参数报错，见 BuiltinMethods 调用点）。

线程模型：注册通常在 eval 前（单线程），执行时只读查表。atomic/mutex 非必需 （MVP 假设注册与执行不并发；GUI 场景由宿主保证时序）。
