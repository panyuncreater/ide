Detailed Description

支配树。基于 Cooper-Harvey-Kennedy 算法计算 immediate dominator。

不变量：

  • idom_[entry] = entry（自支配）
  • idom_[n] 是 n 的严格支配者中离 n 最近的
  • dominates(a, b) 当且仅当 a 在从 entry 到 b 的路径上必经 a
