SyntaxExplorerPanel.cpp — 语法探索面板实现

以「产生式列表 + 说明 + 样例代码/输出」三栏布局，帮助学习者对照 MiniLang 的语法产生式，支持 EBNF / 自然语言 / 混合三种视图模式。 可一键运行样例（Lexer → Parser → Interpreter）并将代码加载到主编辑器。 构造面板：组装顶部按钮栏（运行/加载）、视图模式切换栏，以及 主体三栏（产生式列表 / 说明浏览器 / 样例代码 + 输出）。 用 QButtonGroup 互斥管理三种视图按钮，默认选中「混合」视图并加载首项。
