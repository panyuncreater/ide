## 修复字节码视图点击崩溃

### 根因
OP_CALL 指令编码与反汇编/高亮不一致：
- **Compiler** 写入 4 字节：`opcode(1) + nameIdx_low(1) + nameIdx_high(1) + argCount(1)`
- **Bytecode.h disassembleInstruction** 只读 2 字节（读取位置和步进长度都错）
- **ide.cpp highlightBytecodeLine** 也只步进 2 字节

反汇编器 offset 失步后越界访问 constants[]，导致崩溃。默认示例代码含 `factorial(5)` 等 FunCall，必触发。

### 修复
1. **Bytecode.h** — OP_CALL 的 disassembleInstruction 改为读 4 字节（opcode + nameIdx + argCount），offset += 4
2. **ide.cpp** — highlightBytecodeLine 中 OP_CALL 从 offset += 2 改为 offset += 4；OP_METHOD_CALL 单独列为 offset += 4（之前被合并在 BUILD_ARRAY 里漏掉了）

## 2026-06-05 第二轮修复（5 个问题）

### 1. VM 行号从错误 chunk 获取（🟠 严重）
- **问题**：ide.cpp 从 `lastCompileResult_.mainChunk.lines[currentIP]` 取行号，但 VM 进入函数帧后 IP 在函数 chunk 中，取到错误行号
- **修复**：VM 新增 `getCurrentLine()` 和 `getCurrentChunkName()` 方法，从当前帧的 chunk 获取行号；ide.cpp 改用 `vm_.getCurrentLine()`

### 2. highlightBytecodeLine 只支持 mainChunk（🟠 严重）
- **问题**：VM 进入函数 chunk 后 IP 不在 mainChunk 范围内，高亮失效
- **修复**：ide.h 新增 `ChunkRowInfo` 结构记录 chunk→行号映射；`highlightBytecodeLine` 改为接受 `(chunkName, ip)` 参数；`populateBytecodeList` 填充 `chunkRowMap_`

### 3. OP_CLOSURE 栈泄漏（🟡 中等）
- **问题**：compileFunDecl 中 OP_CLOSURE 推入闭包值但 OP_CALL 通过名字查找不消费它，每个函数声明泄漏一个值
- **修复**：compileFunDecl 中 OP_CLOSURE 后添加 OP_POP

### 4. OP_AND/OP_OR 残缺实现（🟡 中等）
- **问题**：VM 中 OP_AND/OP_OR 缺少 else 分支（Compiler 不生成它们，用短路跳转替代），但代码残缺
- **修复**：补充 else 分支注释，标注 Compiler 当前不生成这些指令

### 5. OP_SET_VAR 栈语义不一致（🟡 中等）
- **问题**：OP_SET_VAR 原来有 `push(val)` 导致赋值语句在栈上残留值；OP_SET_LOCAL 用 peek 不 push 不 pop，语义不统一
- **修复**：去掉 OP_SET_VAR 的 push(val)，使赋值语句 net 0 栈效果；同时去掉 compileForStmt 中 update 后多余的 OP_POP
