## Bug修复 - 格式化多次使用后代码丢失

**根因**：两个 Formatter bug 叠加，导致重新解析时 ParseError → synchronize() 吞掉后续 `}` → 整块代码丢失

1. **formatBlock 给复合语句加 `;`**：`if/while/for/fun/class` 已以 `}` 结尾，再加 `;` 产生 `};`。重解析时 `expressionStatement()` 把 `;` 当表达式起始 → ParseError
2. **formatIfStmt 错误包装 else-if**：`else if` 被输出为 `else { if ... };`，而非 `else if ...`

**修复**：
- 新增 `isSelfTerminating()` 辅助函数，判断 NODE_IF_STMT/WHILE/FOR/FUN/CLASS
- `formatBlock` 和 `formatClassDecl` 对自终止语句不加 `;`
- `formatIfStmt` 检查 elseBranch 是否为 NODE_IF_STMT，直接输出 `else if ...`
- `formatNode` 从 dynamic_cast 链改为 switch(nodeType) 分发
