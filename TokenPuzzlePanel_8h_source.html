1// ============================================================
2// TokenPuzzlePanel.h — 交互式 Token 拼图游戏面板（功能 3）
3// ------------------------------------------------------------
4// 通过游戏化方式理解"词法分析就是切分字符流"。玩家将打乱的
5// token 按正确顺序排列，还原目标语句。
6//
7// UI 布局：
8// 顶部：关卡选择 QComboBox + 得分显示 QLabel + 关卡进度
9// 中部上：目标语句展示（只读）
10// 中部中：打乱的 token 按钮（QPushButton，点击添加到答案区）
11// 中部下：玩家答案区（QListWidget，点击移除）
12// 底部：[✓ 检查答案] [💡 提示] [⏭ 跳过] [🔄 重置] + 反馈 QLabel
13//
14// 交互逻辑：
15// - 点击打乱 token 按钮：添加到答案区末尾，原按钮禁用
16// - 点击答案区 token：移除并恢复对应打乱按钮
17// - 检查答案：逐 token 比对；正确则显示 ⭐ 并解锁下一关；错误则高亮错误位置
18// - 提示：显示 hint 文本，每次使用降低星级评分
19// - 跳过：直接解锁下一关（不计星）
20// - 重置：清空答案区，恢复所有打乱按钮
21//
22// 纯前端游戏，不依赖引擎层（不调用 Lexer/Parser/Interpreter）。
23// ============================================================
