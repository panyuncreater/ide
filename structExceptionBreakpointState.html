Detailed Description

R104 调试器拓展：异常断点状态 单一全局开关，启用后在 throw 语句执行前暂停（对齐 GDB catch throw）。 不支持 catch 入口暂停（设计决策：catch 入口需侵入 try/catch 调度链，复杂度高且 与三后端 try/catch/finally 续跳链布局耦合，故仅支持 throw 暂停）。
