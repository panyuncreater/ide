3// ============================================================
4// JitVisualizerPanel — JIT 编译可视化教学面板（教学板块拓展）
5// ------------------------------------------------------------
6// 可视化 MiniLang JIT 后端（R138-R159，基于 asmjit 的第四套执行引擎）
7// 的核心工作原理，让学习者直观理解字节码 → 本地机器码的编译过程。
8//
9// 五个子页：
10// 1. 编译原理概览：寄存器分配 / 栈帧布局 / JitContext 字段表 /
11// 与 StackVM dispatch loop 对比
12// 2. 类型反馈与特化：内置 3 场景（INT/FLOAT/不特化），面板内部
13// 独立运行 JITBackend，展示 per-chunk 类型反馈与特化决策
14// 3. 热点检测：内置场景展示 per-chunk 调用计数、重编译标志、
15// 热点阈值机制
16// 4. OpCode 覆盖与回退：58 种支持 OpCode 分类表 + 不支持 OpCode
17// 的硬失败行为说明
18// 5. 分层编译与 OSR（R160）：展示 tiered compilation 三级分层
19// (Interpreter→Baseline→Specialized)、OSR 栈帧迁移、lazy
20// compilation、deoptimization 四类运行时指标
21//
22// 设计约束：
23// - 面板内部独立创建 JITBackend 实例运行内置场景（参考 TestJIT.cpp
24// 的 runJIT 模式），不修改 IdeController / 引擎层，避免破坏现有
25// 性能与稳定性。
26// - JIT 默认启用（CMake MINILANG_USE_JIT=ON）。未启用时子页 2/3/5
27// 运行按钮禁用并提示，子页 1/4 静态内容仍可查看。
28// - 所有 JIT getter 只在 execute() 返回后读取（线程安全契约）。
29// ============================================================
